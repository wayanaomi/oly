# Olymors Investment Limited Corporate Website

A professional, responsive, and modern corporate website for Olymors Investment Limited, built with React and Next.js.

## Features
- Corporate, engineering-focused design
- Responsive layout for all devices
- Home, About, Services, Projects, Mission & Vision, Contact pages
- Animated hero, service cards, and project gallery
- SEO optimized with metadata
- Modular React components
- Design tokens and global styles

## Tech Stack
- React + Next.js
- CSS Modules (custom CSS)
- Ready for Framer Motion, AOS, GSAP, Swiper, EmailJS, and more

## Getting Started
1. Install dependencies:
   ```
   npm install
   npm install framer-motion aos swiper react-icons emailjs-com gsap react-countup
   ```
2. Run the development server:
   ```
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project Structure
```
/public
   logo.png
   images/
/src
   components/
   pages/
   styles/
```

## Customization
- Update images in `/public/images` and `/public/logo.png`.
- Edit content in `/src/components` and `/src/pages`.
- Adjust design tokens in `/src/styles/variables.css`.

## SEO
- Metadata is set in `src/components/SEOHead.js` and included on all main pages.
